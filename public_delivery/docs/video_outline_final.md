# 4 分钟录制提纲（最终版）

直接围绕 `public_delivery/scicheck_demo.html` 录。不要为了视频重跑计算、不新增模型调用、不启动科学计算。

## 0:00–0:30 项目问题与目标
操作：
1. 双击打开 `public_delivery/scicheck_demo.html`。
2. 停在首页标题和“本页不新增模型调用或求解启动”提示处。

讲稿：
“SciCheck 解决的是科学计算结果的可验证性问题：把模型给出的候选数值，接到真实求解记录、独立判定、预算限制和失败修复轨迹里。这个页面只回放已经落盘的真实记录，不新增模型调用，也不启动新的计算。”

## 0:30–2:30 窄区间积分先错后修
操作：
1. 切到默认/“数值积分”案例。
2. 点一次“下一步”，停在 `quad_plain` 的失败记录。
3. 再点一次“下一步”，停在 `quad_breakpoints` 的通过记录。
4. 点“重置回放”一次，证明状态可重置。

讲稿：
“这里用窄区间积分做例子。第一次用默认求积，候选结果和独立判定不一致，记录是失败。第二次换成带断点的求积方法，误差进入允许范围，判定通过。注意这不是模型自己改答案，而是任务层按记录执行不同方法，并由独立判定确认结果。”

## 2:30–3:30 求根、线性系统、ODE 代表案例
操作：
1. 点“求根”标签，播放或下一步一次。
2. 点“线性系统”标签，播放或下一步一次。
3. 点“ODE”标签，播放或下一步一次。

讲稿：
“这三类案例分别展示求根、线性系统和 ODE 场景。它们都保留真实 run_id、候选值、预算和判定结果。失败案例也保留，不用通过数量替代证据；统计上我们只按候选执行、回执验证、幂等重放分层，不把开发样例说成模型效果通过率。”

## 3:30–4:10 真实 AGH 宿主闭环与失败记录
操作：
1. 切到带 AGH 宿主层说明的案例。
2. 停在“实际 AGH 会话链接”和费用 `UNKNOWN` 的位置。

讲稿：
“宿主闭环记录的是真实调用链：方法查询、执行、验证、失败和修复。没有已核实公开链接时，页面会明确说明，不使用假链接。官方轨迹需要你在 AGH 界面手动导出；这里费用保持 UNKNOWN，不把未验证内容写成结论。”

## 4:10–4:20 来源、已知边界和交付物
操作：
1. 滚到“来源哈希/JSON 导出”。
2. 点一次“复制 JSON”或“导出当前用例 JSON”。

讲稿：
“每个案例都保留来源哈希和 JSON 导出，用于复核。已知边界是：本页是离线回放，不新增调用；复制失败会提示；官方轨迹和视频由人工完成。交付物是可打开 HTML、最小仓库目录、统计结果和检查脚本。”

## 录前 5 项人工检查
1. 初始打开只高亮一个案例。
2. 上一步/下一步/重置/播放都能用，切换案例后旧播放停止。
3. 390px 宽度下哈希、JSON、长文本不横向撑破。
4. 复制失败时能看到提示。
5. 没有可核实 AGH 链接时，不出现假链接。
