# 手动上传GitHub

目标公开仓库：https://github.com/lankuo4268/SciCheck

1. 打开仓库，点击 Add file → Upload files。
2. 将public_delivery里面的文件和文件夹一起拖入，仓库根应直接出现README.md、scicheck_demo.html、requirements.txt、source/、examples/、docs/、results/。
3. 检查上传列表，不能包含.db、.key、真实绑定、账户配置和官方轨迹原件。
4. 填写提交说明 Publish SciCheck source and interactive demo。选择页面提供的提交方式完成上传；如产生分支/PR，合并后确认main中可见。
5. 在未登录窗口确认仓库可访问。HTML需要下载后打开。
6. 可在Releases创建v0.1.0，填写说明并点击Publish release；Save draft不是公开发布。
7. 保存显示项目名、完整地址和平台实际发布日期的截图。若时间只显示相对值，尝试悬停或展开以显示完整日期。
